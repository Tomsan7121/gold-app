      ヘルプ・用語集

      SMA / EMA（移動平均）

      一定期間の終値の平均。価格が線の上なら上昇基調、下なら下降基調の目安。短期線が長期線を上抜けるとゴールデンクロス（GC）、下抜けるとデッドクロス（DC）。

      ボリンジャーバンド

      移動平均 ± 標準偏差×2。バンド幅が狭まる（スクイーズ）と、その後に値動きが大きくなりやすいと言われます。%B は価格がバンドのどこにあるか（0=下限、1=上限）。

      一目均衡表

      転換線(9)・基準線(26)・先行スパン A/B（26本先にずらす＝雲）・遅行スパン（26本前にずらす）。価格が雲の上なら上昇寄り。

      パラボリック SAR / スーパートレンド

      トレンド追随型の指標。点（線）が価格の下なら上昇トレンド、上なら下降トレンド。反転位置は損切りの目安としても使われます。

      RSI

      0〜100 の値で、70 以上は買われすぎ、30 以下は売られすぎの目安。強いトレンドでは張り付くことがあります。

      MACD

      EMA12 と EMA26 の差。シグナル線（MACD の EMA9）より上なら上昇の勢い。ヒストグラムは差の大きさ。

      ストキャスティクス

      直近14本の高安の中で終値がどこにあるか。80 以上・20 以下で %K と %D がクロスすると反転の兆しとされます。

      ADX / DMI

      ADX はトレンドの強さ（25 以上で強い、20 未満で弱い）。+DI が −DI より上なら上昇方向。

      ATR / ADR

      ATR は1本あたりの平均的な値幅。損切り幅の目安に使われます。ADR は平均日次値幅で、本日の消化率が 100% に近いと残りの値幅は小さいことが多いです。

      CCI / ウィリアムズ%R / ROC / モメンタム

      いずれも勢いを見るオシレーター。CCI は ±100、%R は −20/−80 が目安。ROC・モメンタムは 0 より上で上向き。

      VWAP

      出来高加重平均価格（日本時間 9:00＝UTC 0時にリセット）。日中の平均的な取引コストの目安。ここでの出来高は先物の出来高です。

      ピボット

      前日の高値・安値・終値から計算する当日の目安ライン（P・R1〜3・S1〜3）。カマリラは終値中心の狭いライン。

      フィボナッチ・リトレースメント

      直近の高値と安値の間を 23.6% / 38.2% / 50% / 61.8% などで区切った押し目・戻りの目安。

      ダイバージェンス

      価格は安値（高値）を更新したのに RSI は更新しない状態。勢いの衰えの可能性を示します（「可能性」の表示です）。

      先物とスポット・週末の足

      チャートは暗号資産取引所の金の無期限先物で、スポット価格とは数ドルずれることがあります（ベーシス）。先物は週末も動くため、FX 業者の MT4 等とは週末を含む期間の指標値がずれます。

      セッション

      東京 9:00–18:00、ロンドン 8:00–17:00（現地）、NY 8:00–17:00（現地）。夏時間は自動で反映します。ロンドンと NY の重複時間帯は値動きが大きくなりやすいとされます。
